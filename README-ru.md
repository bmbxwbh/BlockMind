## Почему BlockMind

### 1. Система памяти — AI учится

Традиционные AI-компаньоны забывают всё после перезапуска. У BlockMind три уровня постоянной памяти:

- **Пространственная память**: Автоматически запоминает защитные зоны зданий, опасные области, точки ресурсов
- **Память путей**: Запоминает успешные маршруты, заносит неудачные в чёрный список
- **Стратегическая память**: Успешные операции становятся переиспользуемыми стратегиями с нулевым расходом Token

AI автоматически обходит постройки игроков при навигации, никогда не разрушает дом.

### 2. Архитектура двойного агента — экономия Token

```
Главный агент (~50 Token/запрос): только чат + распознавание намерений
Агент операций (<1500 Token/запрос): без состояния, одноразовый
```

В сравнении с одиночным агентом (>4000 Token/запрос), экономия 84%.

### 3. Режим сервера и клиента

| Режим | Место установки | Игрок | Сценарий |
|-------|----------------|-------|----------|
| Сервер | `mods/` на сервере | FakePlayer (бот) | Сервер 7×24 |
| Клиент | `mods/` в клиенте | Локальный игрок | Одиночная игра / LAN |

### 4. Baritone + защита зданий

AI использует Baritone для навигации (копание/мосты/плавание), но автоматически обходит защитные зоны зданий. Постройки из памяти внедряются как зоны исключения Baritone.

### 5. Skill DSL + маркетплейс

Определение переиспользуемых навыков AI на YAML (добыча, строительство, фермерство), обмен в сообществе. Навыки, созданные AI, автоматически сохраняются и выполняются с нулевым расходом Token.

## Быстрый старт

### Требования

- Python 3.10+ · Java 17+ · Minecraft 1.20.0 ~ 26.1.2

### Запуск

```bash
git clone https://github.com/bmbxwbh/BlockMind.git
cd BlockMind
chmod +x start.sh && ./start.sh
```

### Windows

```cmd
git clone https://github.com/bmbxwbh/BlockMind.git
cd BlockMind
install.bat
start_all.bat
```

### Docker

```bash
docker pull ghcr.io/bmbxwbh/blockmind:latest
docker run -d --name blockmind -p 19951:19951 \
  -v ./config.yaml:/app/config.yaml:ro \
  ghcr.io/bmbxwbh/blockmind:latest
```

### Конфигурация

Отредактируйте `config.yaml`:

```yaml
ai:
  main_agent:
    provider: openai
    api_key: "sk-your-key"
    model: gpt-4o
webui:
  enabled: true
  port: 19951
```

После запуска перейдите на `http://localhost:19951` для доступа к панели управления.

## FAQ

**Q: Обязательно устанавливать Baritone?** Нет, без него используется базовый A*.

**Q: Где хранятся данные памяти?** В `data/memory/`, 5 JSON-файлов.

**Q: Какие провайдеры AI поддерживаются?** Формат OpenAI (DeepSeek/OpenRouter/MiMo) + Anthropic.

**Q: Можно ли в одиночной игре?** Да, поместите Mod в `mods/` клиента.
