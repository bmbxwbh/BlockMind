## لماذا BlockMind

### 1. نظام ذاكرة — AI يتعلم

الألياف التقليدية تنسى كل شيء بعد كل إعادة تشغيل. BlockMind لديه ثلاثة طبقات من الذاكرة الدائمة:

- **ذاكرة مكانية**: تحفظ تلقائيًا مناطق حماية المباني والمناطق الخطرة ونقاط الموارد
- **ذاكرة المسارات**: تتذكر المسارات الناجحة وتضيف الفاشلة للقائمة السوداء
- **ذاكرة الاستراتيجيات**: العمليات الناجحة تتحول إلى استراتيجيات قابلة لإعادة الاستخدام بـ Zero Token

AI يت避开 تلقائيًا مباني اللاعب أثناء التنقل، لا يدمر المنزل أبدًا.

### 2. بنية وكيل مزدوج — توفير Token

```
الوكيل الرئيسي (~50 Token/مرة): فقط محادثة + تحديد النية
وكيل التنفيذ (<1500 Token/مرة): بلا حالة، يُستخدم ويُلقى
```

مقارنة بـ single Agent (>4000 Token/مرة)، يوفر 84% من التكلفة.

### 3. وضع الخادم والعميل

| الوضع | الموقع | اللاعب | السيناريو |
|-------|--------|--------|-----------|
| خادم | مجلد `mods/` بالخادم | FakePlayer (بوت) | خادم 7×24 |
| عميل | مجلد `mods/` بالعميل | لاعب محلي | ألعاب فردية / LAN |

### 4. Baritone + حماية المباني

AI يستخدم Baritone للتنقل (حفر/بناء جسور/سباحة)، لكن يتجاوز تلقائيًا مناطق حماية المباني المحددة. المباني في الذاكرة تُحقن كمناطق استبعاد في Baritone.

### 5. Skill DSL + سوق

تعريف مهارات AI بإعادة استخدام YAML (حفر، زراعة، بناء)، مشاركة مجتمعية. المهارات التي ينشئها AI تُحفظ وتُنفذ لاحقًا بـ Zero Token.

## البدء السريع

### المتطلبات

- Python 3.10+ · Java 17+ · Minecraft 1.20.0 ~ 26.1.2

### التشغيل

```bash
git clone https://github.com/bmbxwbh/BlockMind.git
cd BlockMind
chmod +x start.sh && ./start.sh
```

### Windows

```cmd
git clone https://github.com/bmbxwbh/BlockMind.git
cd BlockMind
install.bat
start_all.bat
```

### Docker

```bash
docker pull ghcr.io/bmbxwbh/blockmind:latest
docker run -d --name blockmind -p 19951:19951 \
  -v ./config.yaml:/app/config.yaml:ro \
  ghcr.io/bmbxwbh/blockmind:latest
```

### الإعدادات

حرر `config.yaml`:

```yaml
ai:
  main_agent:
    provider: openai
    api_key: "sk-your-key"
    model: gpt-4o
webui:
  enabled: true
  port: 19951
```

بعد التشغيل، افتح `http://localhost:19951` للوصول إلى لوحة التحكم.

## WebUI

`http://localhost:19951` — رموز Lucide + ثيم MiuiX الداكن

| الميزة | الوصف |
|--------|-------|
| لوحة معلومات | حالة مباشرة، أوامر سريعة، تدفق أحداث |
| إدارة Skill | تحرير YAML عبر الإنترنت، تنفيذ بنقرة |

| إعدادات النموذج | تكوين وكيل مزدوج، تبديل مباشر |
| إعدادات الأمان | مستوى المخاطر، سجل التدقيق |
| قائمة المهام | مراقبة حالة التنفيذ |
| مركز السجلات | تدفق سجلات WebSocket مباشرة |

## الأسئلة الشائعة

**س: هل يجب تثبيت Baritone؟** لا، بدونه يعود إلى A* الأساسي.

**س: أين تُخزَّن بيانات الذاكرة؟** في مجلد `data/memory/`، 5 ملفات JSON.

**س: ما مزودي AI المدعومين؟** صيغة OpenAI المتوافقة (DeepSeek/OpenRouter/MiMo) + Anthropic.

**س: هل يمكن استخدامه في ألعاب فردية؟** نعم، ضع Mod في مجلد العميل `mods/`.
